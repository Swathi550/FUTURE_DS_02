# 📊 Facebook Ads Campaign Performance Analysis Dashboard

## 📌 Project Overview
This project focuses on analyzing Facebook advertising campaign performance to understand how different ads perform across key marketing metrics. The analysis involves data cleaning, KPI evaluation, and data visualization using Power BI to support data-driven marketing decisions.

This project was completed as part of Data Science & Analytics Task 2 under the Future Interns Internship Program.

---

## 🎯 Objectives
- Analyze Facebook ad campaign performance
- Track key digital marketing metrics
- Understand audience engagement behavior
- Identify top-performing ads and campaigns
- Visualize insights using interactive dashboards

---

## 📂 Dataset
- Source: Kaggle – Facebook Ads Performance Dataset
- File Type: CSV
- The dataset contains information such as impressions, clicks, spend, CTR, gender, age group, and campaign details.

---

## 🛠️ Tools & Technologies
- Power BI
- Excel / CSV
- Data Visualization Techniques

---

## 🔍 Steps Performed
1. Imported and explored the Facebook Ads dataset
2. Cleaned and prepared the data for analysis
3. Identified important marketing KPIs
4. Analyzed campaign-wise and audience-wise performance
5. Created an interactive Power BI dashboard
6. Derived insights and actionable recommendations

---

## 📈 Key Insights
- Certain Facebook campaigns achieved higher engagement
- Higher ad spend generally resulted in increased clicks
- Audience segments showed different engagement patterns
- CTR helped measure ad effectiveness beyond impressions
