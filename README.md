Facebook Ads Campaign Performance Analysis Dashboard

Project Overview
This project focuses on analyzing and visualizing Facebook advertising campaign performance to understand how ads perform across key marketing metrics. The analysis helps evaluate campaign effectiveness and supports data-driven decision-making using interactive dashboards.

This project was completed as part of Data Science & Analytics Task 2 under the Future Interns Internship Program.

Objectives
- Analyze Facebook ad campaign performance
- Track key digital marketing KPIs
- Understand audience engagement behavior
- Identify top-performing ads and campaigns
- Present insights using interactive visualizations

Dataset
Source: Kaggle – Facebook Ads Performance Dataset
File Type: CSV
The dataset includes information such as impressions, clicks, spend, CTR, gender, age group, and campaign details.

Tools & Technologies
- Power BI
- Excel / CSV
- Data Visualization Techniques

Steps Performed
1. Imported and explored the Facebook Ads dataset
2. Cleaned and prepared the data for analysis
3. Identified important marketing KPIs
4. Analyzed campaign-wise and audience-wise performance
5. Built an interactive Power BI dashboard
6. Derived insights and improvement recommendations

Key Insights
- Some Facebook campaigns achieved higher engagement than others
- Increased ad spend generally resulted in more clicks
- Audience segments showed different engagement patterns
- CTR helped measure ad effectiveness beyond impression
