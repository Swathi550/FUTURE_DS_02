📊 Social Media Campaign Performance Analysis Dashboard
📌 Project Overview
This project focuses on analyzing and visualizing Facebook advertising campaign performance to understand how ads perform across different metrics. The analysis helps evaluate campaign effectiveness and supports data-driven marketing decisions through interactive dashboards.
This project was completed as part of Data Science & Analytics Task 2 under the Future Interns Internship Program.
🎯 Objectives
Analyze Facebook ad campaign performance
Track key digital marketing KPIs
Understand audience engagement behavior
Identify top-performing ads and campaigns
Present insights through interactive visualizations
📂 Dataset
Source: Kaggle – Facebook Ads Performance Dataset
File Type: CSV
The dataset contains ad performance details such as impressions, clicks, spend, CTR, gender, age group, and campaign information.
🛠️ Tools & Technologies
Power BI
Excel / CSV
Data Visualization Techniques
🔍 Steps Performed
Imported and explored the Facebook Ads dataset
Cleaned and prepared the data for analysis
Identified key marketing KPIs
Analyzed campaign-wise and audience-wise performance
Built an interactive Power BI dashboard
Derived insights and improvement recommendations
📈 Key Insights
Some Facebook campaigns achieved significantly higher engagement
Higher ad spend generally led to increased clicks
Audience segments responded differently to ads
CTR provided a clear measure of ad effectiveness
